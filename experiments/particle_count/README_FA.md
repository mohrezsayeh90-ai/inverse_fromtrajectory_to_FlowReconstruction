# آزمون اثر تعداد ذرات بر بازیابی پروفیل سرعت ورودی

هدف، مقایسهٔ ۲، ۳، ۴، ۵ و ۶ مسیر زمان‌دار برای ده ورودی است.
این یک مسئلهٔ بازسازی جریان پایا است؛ پروفیل برحسب ارتفاع تغییر می‌کند.
فایل‌های خروجی در `results/particle_count/` هستند.
متن پایان‌نامه در این مرحله تغییر نمی‌کند.

## طراحیِ ثابتِ مقایسه

- کانال `5 × 1`، رینولدز مرجع ۳۰ و میانگین حقیقی سرعت یک است.
- شش نقطهٔ پرتاب و سرعت اولیه در `campaign.py` مشخص‌اند.
- نخستین دو پرتاب از دو سوی متفاوت کانال هستند.
- چهار پرتاب اضافی، نواحی مختلف نزدیک ورودی را می‌سنجند.
- هر تعداد ذره دقیقاً از پیشوند همان شش پرتاب استفاده می‌کند.
- زمان پاسخ استوکس همهٔ ذرات `0.42` و افق مشاهده `1.2` است.
- هر ذره ۸۱ موقعیت زمان‌دار دارد.
- نویز هر مختصه، گاوسی با انحراف معیار `2e-4 H` است.
- موقعیت اولیه دقیق نگه داشته می‌شود.
- تحقق نویز هر مسیر در تمام مقایسه‌های افزایشی ثابت است.
- تعداد گره‌های ورودی ۶۵ و میانگین سرعت نیز مجهول است.
- همهٔ حالت‌ها دو شروع یکسان و سقف ۲۰۰ تکرار دارند.
- وزن‌های اپراتور ثابت‌اند؛ آموزش جدیدی انجام نمی‌شود.
- شروع بهتر فقط با هزینهٔ برازش انتخاب می‌شود.
- ورودی حقیقی در برازش، مقداردهی اولیه یا انتخاب شروع استفاده نمی‌شود.
- از جواب تعداد قبلی به‌عنوان شروع تعداد بعدی استفاده نمی‌شود.

بودجه، منظم‌سازی و فرمول هزینه در تمام ۵۰ حالت یکسان‌اند.
تابع هدف همان `flow_reconstruction/inverse.py` است.
میانگین‌گیری هزینه روی ذرات، قدرت نسبی منظم‌سازی را ثابت نگه می‌دارد.
تبدیل متغیر، قید مثبت‌بودن اسپلاین و جریمهٔ فیزیکی نیز حفظ شده‌اند.
برنامهٔ JAX با دادهٔ متغیر برای پنج اندازه بازاستفاده می‌شود.
این کار فقط از کامپایل تکراری جلوگیری می‌کند.
مقدار هزینه و گرادیان با پیاده‌سازی اصلی کنترل شده‌اند.
تشخیص SVD ژاکوبین در این پیمایش محاسبه نمی‌شود.
هیچ ادعای رتبه، یکتایی یا بازهٔ اطمینان از آن نتیجه نمی‌شود.

## مرجع مستقل و ترتیب پروفیل‌ها

هفت مرجع اجزای محدودِ موجود در رینولدز ۳۰ بازاستفاده می‌شوند.
برای ورودی تقریباً تخت و نه‌نوسانی، دو مش تازه حل می‌شوند.
مرجع سهموی از حل تحلیلی پوازوی می‌آید.
سرعت ورودی همهٔ این پروفیل‌ها با میانگین مشترک یک نرمال می‌شود.
دو ورودی رزروشدهٔ آزمون مستقیم در این مطالعه استفاده نمی‌شوند.

مسیرها از میدان FEM با میان‌یابی خطیِ داخلی تولید می‌شوند.
همهٔ نقاط پرتاب داخل محدودهٔ نمونه‌برداری مرجع قرار دارند.
هیچ برون‌یابی یا گرهٔ مرزیِ ساختگی استفاده نمی‌شود.
خطای پالایش مش و حساسیت حل مسیر ذخیره می‌شوند.
مدل آموزش‌دیده، مسیرهای مرجع را تولید نمی‌کند.

ترتیب نمایش برحسب RMS مشتق دوم پروفیل حقیقی است.
این معیار، تندی تغییرات مکانی را اندازه می‌گیرد.
تعداد قله‌ها به‌تنهایی معیار پیچیدگی در این ترتیب نیست.
مثلاً ورودی تقریباً تخت، لایه‌های باریک نزدیک دیواره دارد.
این ترتیب پیش از مقایسهٔ خطاهای بازسازی تعیین می‌شود.

## بازتولید

از ریشهٔ مخزن و با Python 3.12 اجرا کنید.
وابستگی‌ها در `requirements-cpu-tested.txt` هستند.
برای FEM، `scikit-fem==12.0.2` نیز لازم است.

```sh
python -m venv /workspace/flow-env
/workspace/flow-env/bin/pip install -r requirements-cpu-tested.txt scikit-fem==12.0.2

for profile in parabolic beta5 skew_b3 flat30 twin_b3_r30 shoulder mixed waves3_r30 lobes4_r30 nine30; do
  OPENBLAS_NUM_THREADS=1 /workspace/flow-env/bin/python experiments/particle_count/campaign.py --prepare "$profile"
  OPENBLAS_NUM_THREADS=1 /workspace/flow-env/bin/python experiments/particle_count/campaign.py --observations "$profile"
done

OPENBLAS_NUM_THREADS=1 /workspace/flow-env/bin/python experiments/particle_count/fit_campaign.py
OPENBLAS_NUM_THREADS=1 /workspace/flow-env/bin/python experiments/particle_count/summarize.py
```

هر برازش تکمیل‌شده برای ادامهٔ اجرا بازاستفاده می‌شود.
برای اجرای موازی، `--worker i --workers k` پروفیل‌ها را تقسیم می‌کند.
هر worker یک هستهٔ مجاز را استفاده می‌کند.
حالت `--profile-only parabolic --parity` کنترل روش را نیز ذخیره می‌کند.
فایل `design.json` تنظیمات ازپیش‌تعیین‌شدهٔ اجرای منتشرشده را ثبت می‌کند.
همهٔ شروع‌ها، توقف‌ها، ضرایب، ورودی‌ها و بازپخش‌ها حفظ می‌شوند.
برای تغییر طراحی، خروجی قبلی را با آزمایش تازه مخلوط نکنید.

## تفسیر نتیجه

خطای اصلی، نرم نسبی پروفیل در واحد `U_ref` است.
خطای شکل نرمال‌شده و میانگین سرعت نیز جدا ثبت می‌شوند.
تطبیق مسیر، به‌تنهایی دقت ورودی را ثابت نمی‌کند.
افزودن ذره، هم داده و هم پوشش مکانی را افزایش می‌دهد.
این آزمایش این دو اثر را از یکدیگر جدا نمی‌کند.
دو شروع بهینه‌سازی، تکرار مستقل آزمایش فیزیکی یا بازهٔ اطمینان نیستند.
این مطالعه یک تحقق نویز را بررسی می‌کند.
اثر ذرات بر جریان و اندرکنش میان ذرات در مدل حذف شده‌اند.
نتیجه به چیدمان، بودجه، پیشین و اپراتور فعلی مشروط است.
اپراتور مستقیم قبلی هنوز همهٔ معیارهای پذیرش را برآورده نکرده است.

پروفیل سهموی با شکل پایهٔ مقداردهی اولیه و پیشین هموارسازی منطبق است.
بنابراین خطای بسیار کم آن را نباید فقط به تعداد ذرات نسبت داد.
همگرایی بهینه‌ساز و دقت پروفیل، دو معیار مستقل گزارش می‌شوند.
