# زنجیره‌های اصلاح‌شده

فقط سه زنجیرهٔ تصویری در `chains_only.pdf` آمده است. پنل دوم فقط ورودی تخمینی روش بدون زمان را دارد. پنل ششم دو نمودار x(t) و y(t) را برای دو ذره و هر دو روش نشان می‌دهد؛ خط پیوسته بدون زمان و خط‌چین با زمان است. در روش بدون زمان، محور t ساعت تخمینی است؛ هیچ کشش یا نرمال‌سازی زمانی برای منطبق‌کردن منحنی‌ها انجام نشده است. تمام زمان‌ها بی‌بعدند.

این تغییر فقط نمایش نتایج است؛ هیچ برازش، پارامتر، داده یا خروجی قبلی تغییر نکرده است. بازتولید از ریشهٔ مخزن: `python flow_reconstruction_no_time/chain_revision_xt_yt/build.py`
