## روش و حدود مقایسه

برازش فقط منحنی مرتب $x,y$، سرعت اولیهٔ معلوم و عدد استوکس ۰٫۴۲ را می‌خواند. برای هر ذره ساعت مثبت مستقل استنتاج می‌شود. هندسه با ۶۵ نقطهٔ طول‌قوسی نمایش داده شد. هر ساعت ۱۷ گره دارد و هر برازش دو شروع دارد.
ساعت پیشوند مکانی با تقریب فیزیکی سرعت رهاسازی مقداردهی شد. سقف اصلی ۲۵۰ تکرار برای هر شروع است. وزن SOAP گام ۳۱۴٬۰۰۰ در تمام اجراها ثابت بود. هش وزن `e46687f8d50818329072eca1af7c70136fb9e3d314207f89e9427ccc140dfbf9` است.

مرجع اجزای محدود در امتیازدهی پس از برازش استفاده شد. مسیرهای آزمون مستقلاً از شرایط اولیه بازپخش شدند. در مسیرهای آموزش، افق بازپخش از ساعت تخمینی است. برای مسیرهای آزمون، افق آرشیوی فقط در ارزیابی پس از برازش استفاده شد. اعتبارسنجی مسیر آزمون، آزمون استنتاج مدت حرکت نیست.

مقایسهٔ موضعی صفحهٔ ۱۳۰ دو تخمین‌گر متفاوت دارد. روش زمان‌دار از اسپلاین موضعی استفاده می‌کند. روش هندسی از SOAP ثابت در حلقهٔ وارون استفاده می‌کند. انتخاب دادهٔ هندسی فقط با حد مکانی انجام شد. آزمون حساسیت با سه پروفایل، هر دو بذر و هر دو طراحی اجرا شد. در آن، هم شروع ساعت و هم سقف تکرار تغییر کرد. سهم جداگانهٔ این دو تغییر از آزمون حساسیت معلوم نمی‌شود.

میانهٔ خطای هندسی ترکیبی ۲۲٫۷۴٪ بود.
میانه‌های زمان‌دار به‌ترتیب ۱۰٫۳۶٪ و ۱٫۵۹٪ بودند.
در ۳ مورد از ۳۶ مقایسه، خطای هندسی کمتر بود.

از ۱٬۷۲۸ بازپخش برازش، ۱٬۷۲۶ بازپخش کامل شد.
هر ۲۸۸ بازپخش مسیرهای آزمون به افق ارزیابی رسیدند.

در هر ۱۲ مقایسهٔ حساسیت، خطای پروفایل کمتر شد.

خطای نه‌نوسانی در طراحی ترکیبی همچنان بالاتر از آستانه بود.
در آزمون موضعی با ۹۶ ذره، خطای هندسی دو بذر ۴۲٫۴۶٪ و ۴۳٫۵۰٪ بود.

این خروجی برای مقایسهٔ آزمایشی و بحث محدودیت بازیابی ورودی مناسب است.

## بازتولید

نسخهٔ پایهٔ داده‌ها `a9984f07e91680eb22e2a236e74116190d0cb210` است. دستورها از ریشهٔ مخزن اجرا می‌شوند. محیط آزمایش Python 3.12، JAX/JAXlib 0.11.1، NumPy 2.3.5، SciPy 1.17.0 و Matplotlib 3.10.8 داشت.

```bash
export OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 JAX_ENABLE_X64=true
export PYTHONDONTWRITEBYTECODE=1
profiles="beta5 skew_b3 flat30 twin_b3_r30 shoulder mixed waves3_r30 lobes4_r30 nine30"
for seed in 39421 53129; do
  python -m flow_reconstruction_no_time.soap_campaign.fit $profiles --seed "$seed"
  python -m flow_reconstruction_no_time.soap_campaign.replay $profiles --seed "$seed"
  python -m flow_reconstruction_no_time.soap_campaign.spatial_prefix --seed "$seed"
  python -m flow_reconstruction_no_time.soap_campaign.sensitivity --seed "$seed"
done
python -m flow_reconstruction_no_time.soap_campaign.archive adaptive $profiles
python -m flow_reconstruction_no_time.soap_campaign.archive near nine30
python -m flow_reconstruction_no_time.soap_campaign.verify_cache
python -m flow_reconstruction_no_time.soap_campaign.report
python -m flow_reconstruction_no_time.soap_campaign.thesis_report adaptive near
```
